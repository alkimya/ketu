<objective>
Derive `body_decl_speed` in the composite path per D-01: finite difference on the
composite's OWN frozen (λ, β) advanced by their midpoint velocities over Δt=0.01 d —
NEVER the midpoint of the parents' `body_decl_speed`, NEVER re-fetching real
planetary positions at the (meaningless) composite jd, NEVER calling `compute_chart`.
Pin synastry inheritance with a test.

Purpose: The composite has no canonical jd, so dδ/dt must be self-consistent with
the composite's frozen chart (the same trap `body_decl` solved in v1.5). dβ/dt
matters: for the Moon, Δβ contributes 2.6× more to Δδ than Δλ over Δt=0.01 d, so
it cannot be zeroed. DSPD-03 forbids averaging the parents' speed; a ratchet test
proves the composite value differs from that naïve midpoint.

Output: `calculate_composite(...).body_decl_speed` populated self-consistently;
the anti-averaging ratchet test green; synastry inheritance pinned.
</objective>
