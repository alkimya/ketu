<objective>
Populate `body_decl_speed` in the natal path (`compute_chart`) via a vectorised
forward finite difference at Δt=0.01 d, and add the chart-level
`is_ascending_declination_chart(chart)` helper. Pin that returns inherit the field
for free.

Purpose: This is the primary user-facing deliverable — Rahu consumes the natal
`CHART_DTYPE`. The field must equal the v1.5 scalar `declination_velocity(jd, body)`
exactly (Δ==0, success criterion 40.1 / DSPD-02), and the helper lets Rahu classify
ascending/descending/neutral by reading a field and checking a sign, computing no
astronomy of its own (DSPD-06).

Output: `compute_chart(...).body_decl_speed` populated over `S+(14,)`;
`is_ascending_declination_chart` exported from `ketu.charts`; returns pinning test.
</objective>
