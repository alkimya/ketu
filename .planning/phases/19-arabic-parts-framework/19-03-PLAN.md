Then the 5 oracle tests. For each, derive `expected` from the raw chart fields using the SAME formula
the implementation uses, then assert against `calculate_part(...)`:

```python
def _fields(chart):
    return (float(chart["asc"]), float(chart["body_lons"][0]),
            float(chart["body_lons"][1]), float(chart["body_lons"][3]))  # asc, sun, moon, venus

# 1. Fortune — DAY: ASC + Moon - Sun
asc, sun, moon, venus = _fields(DAY_CHART)
expected = (asc + moon - sun) % 360.0
assert abs(calculate_part("fortune", DAY_CHART) - expected) < 1e-9

# 2. Fortune — NIGHT: ASC + Sun - Moon
asc, sun, moon, venus = _fields(NIGHT_CHART)
expected = (asc + sun - moon) % 360.0
assert abs(calculate_part("fortune", NIGHT_CHART) - expected) < 1e-9

# 3. Spirit — DAY: ASC + Sun - Moon
asc, sun, moon, venus = _fields(DAY_CHART)
expected = (asc + sun - moon) % 360.0
assert abs(calculate_part("spirit", DAY_CHART) - expected) < 1e-9

# 4. Spirit — NIGHT: ASC + Moon - Sun
asc, sun, moon, venus = _fields(NIGHT_CHART)
expected = (asc + moon - sun) % 360.0
assert abs(calculate_part("spirit", NIGHT_CHART) - expected) < 1e-9

# 5. Marriage — once, identical across sect: (2*ASC + 180 - Venus) % 360
asc, sun, moon, venus = _fields(DAY_CHART)
expected = (2.0 * asc + 180.0 - venus) % 360.0
m_day   = calculate_part("marriage", DAY_CHART)
m_night = calculate_part("marriage", NIGHT_CHART)
assert abs(m_day - expected) < 1e-9
# Marriage uses ASC+Venus only — different charts give different ASC, so assert the FORMULA holds on
# each chart (sect-invariance is proven by the day/night formula being the same callable, tested in
# the registry suite). Pin the DAY_CHART value as the canonical oracle.
```

  the formula and pins the body-index access (0=Sun, 1=Moon, 3=Venus) + the sect selection.
- The Fortune-day and Spirit-day formulas are MIRRORS — test #1 and #3 must give DIFFERENT values

- Tolerance `1e-9` (machine precision — pure arithmetic, no iteration, mirrors composite f8-exact).
- Tests run OFFLINE.
