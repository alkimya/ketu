### Task 2 — Implémenter `_vectorised_body_properties` (helper privé) dans `ketu/charts/api.py`

Ajoute le helper privé au-dessus de `compute_chart` :

```python
import numpy as np
from ketu.ephemeris.planets import calc_planet_position_batch


_BODY_COUNT = 13  # frozen per D-08 ; mirrors len(ketu.core.bodies)


def _vectorised_body_properties(
    jd_b: np.ndarray,
) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """Compute per-body lon/lat/speed for a broadcast jd array.

    Loops over the 13 canonical bodies (NOT over the leading shape S).
    Each iteration calls ``calc_planet_position_batch`` which is natively
    vectorised on jd, so total Python loop count is constant in S.

    Parameters
    ----------
    jd_b : np.ndarray
        Broadcast Julian Date array, leading shape S (any compatible shape).

    Returns
    -------
    body_lons : np.ndarray
        Shape ``S + (13,)``, dtype f8, ecliptic longitudes (degrees [0, 360)).
    body_lats : np.ndarray
        Shape ``S + (13,)``, dtype f8, ecliptic latitudes (degrees).
    body_speeds : np.ndarray
        Shape ``S + (13,)``, dtype f8, longitude speeds (deg/day, negative => retrograde).
    """
    jd_flat = jd_b.ravel()  # shape (M,)
    n = jd_flat.size
    lons = np.empty((n, _BODY_COUNT), dtype=np.float64)
    lats = np.empty((n, _BODY_COUNT), dtype=np.float64)
    speeds = np.empty((n, _BODY_COUNT), dtype=np.float64)
    for body_id in range(_BODY_COUNT):
        # calc_planet_position_batch returns (n, 6): [lon, lat, dist,
        # lon_speed, lat_speed, dist_speed]
        batch = calc_planet_position_batch(jd_flat, body_id)
        lons[:,   body_id] = batch[:, 0]
        lats[:,   body_id] = batch[:, 1]
        speeds[:, body_id] = batch[:, 3]
    tail_shape = jd_b.shape + (_BODY_COUNT,)
    return (
        lons.reshape(tail_shape),
        lats.reshape(tail_shape),
        speeds.reshape(tail_shape),
    )
```

**Pourquoi ce helper et pas `body_properties` / `positions`** : pitfall RESEARCH §Pitfall 1. `body_properties` est `lru_cache(maxsize=1024)`, scalar-only ; `positions` boucle Python. `calc_planet_position_batch` est la seule primitive vraiment vectorisée sur jd. La boucle Python sur **13 corps** est constante en S — c'est l'asymptote optimale sans toucher `ephemeris/planets.py`.

### Task 3 — Implémenter `compute_chart` (sans aspect_matrix encore)

Remplace le stub par :

```python
from ketu.houses import calculate_houses
from ketu.charts.core import CHART_DTYPE
# AspectSetSpec déjà importé en 14-01


def compute_chart(
    jd: ArrayLike,
    lat: ArrayLike,
    lon: ArrayLike,
    system: str = "placidus",
    aspects: AspectSetSpec = None,
    polar_fallback: Literal["raise", "porphyry"] = "raise",
) -> np.ndarray:
    # 1. Broadcast (mirror calculate_houses houses/api.py:107-114)
    jd_a  = np.asarray(jd,  dtype=np.float64)
    lat_a = np.asarray(lat, dtype=np.float64)
    lon_a = np.asarray(lon, dtype=np.float64)
    jd_b, lat_b, lon_b = np.broadcast_arrays(jd_a, lat_a, lon_a)
    S = jd_b.shape

    # 2. Houses (one call covers cusps + ASC/MC/ARMC/Vertex + polar dispatch)
    houses = calculate_houses(
        jd_b, lat_b, lon_b,
        system=system, polar_fallback=polar_fallback,
    )

    # 3. Body positions vectorised on S
    body_lons, body_lats, body_speeds = _vectorised_body_properties(jd_b)

    # 4. Aspect matrix : initialised to sentinels for now ; plan 14-03
    #    will replace this with a real call to _build_aspect_matrix(...).
    # NOTE: 'aspects' parameter is accepted for API stability but not yet
    # consumed ; plan 14-03 will wire it. Documented loudly in docstring.
    aspect_matrix = np.full(S + (_BODY_COUNT, _BODY_COUNT), -1,    dtype=np.int8)
    aspect_orbs   = np.full(S + (_BODY_COUNT, _BODY_COUNT), np.nan, dtype=np.float32)

    # 5. Assemble structured output
    out = np.empty(S, dtype=CHART_DTYPE)
    out["jd"]            = jd_b
    out["lat"]           = lat_b
    out["lon"]           = lon_b
    out["system"]        = system.lower()
    out["body_lons"]     = body_lons
    out["body_lats"]     = body_lats
    out["body_speeds"]   = body_speeds
    out["cusps"]         = houses["cusps"]
    out["asc"]           = houses["asc"]
    out["mc"]            = houses["mc"]
    out["armc"]          = houses["armc"]
    out["vertex"]        = houses["vertex"]
    out["aspect_matrix"] = aspect_matrix
    out["aspect_orbs"]   = aspect_orbs
    return cast(np.ndarray, out)
```
