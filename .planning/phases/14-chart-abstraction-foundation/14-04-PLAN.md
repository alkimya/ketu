```python
def is_day_chart(
    jd: ArrayLike,
    lat: ArrayLike,
    lon: ArrayLike,
) -> np.ndarray:
    """Return True when the Sun is at or above the horizon (sunrise inclusive).

    Sect determination per the Hellenistic convention used by Solar Fire,
    Astro.com, and Robert Hand: the Sun is considered "diurnal" (day) when
    it sits in houses 7 through 12 (the above-horizon hemisphere) and
    "nocturnal" (night) otherwise. Sunrise (Sun on the ASC) resolves to
    **day** ; see Notes for the geometric definition.

    Parameters
    ----------
    jd : float or np.ndarray
        Julian Date(s), UT.
    lat : float or np.ndarray
        Geographic latitude(s), degrees. Polar latitudes (|lat| > polar
        circle) are handled via internal Porphyry fallback (see Notes).
    lon : float or np.ndarray
        Geographic longitude(s), east-positive, degrees.

    Returns
    -------
    np.ndarray
        Boolean array of shape ``np.broadcast_shapes(jd, lat, lon)``.
        ``True`` where the Sun is in houses 7..12 (above horizon = day),
        ``False`` otherwise (below horizon = night).

    Notes
    -----
    **Sect convention (D-13).** Sunrise-inclusive: a Sun exactly at the
    ASC ecliptic longitude is mapped to house 1 by ``house_of`` (the
    package-wide convention is "cusps[i] BEGINS house i+1"). In practice,
    the strict equality ``Sun == ASC`` has measure-zero on real data
    (sub-arcsecond Sun position vs sub-arcsecond ASC computation), so
    this implementation returns ``sun_house >= 7`` directly without a
    dedicated ``np.isclose`` branch. Synthetic deltas of ±0.01° around
    the ASC are pinned by tests to validate the convention.

    **Polar safety (D-15).** This function calls ``calculate_houses``
    internally with ``polar_fallback="porphyry"`` so callers at high
    latitudes (Reykjavík, Tromsø, Arabic Parts at lat > 66.5°) do not
    fail silently or raise. Porphyry house cusps are mathematically
    defined at every latitude. The user-facing ``compute_chart`` does
    not impose this fallback ; ``is_day_chart`` does, by design, because
    the sect helper must always return a bool answer.

    **Geometric definition (D-14).** The above-horizon hemisphere maps
    to houses 7..12 (DESC..MC..ASC, eastward). ``house_of(sun_lon, cusps)``
    yields the Sun's natal house in [1, 12] ; ``return sun_house >= 7``
    expresses the day/night split.

    Examples
    --------
    Scalar input (J2000 Paris noon UT — Sun should be near MC, day):

    >>> is_day_chart(2451545.0, 48.8566, 2.3522)
    array(True)

    Vectorised input (a vernal equinox at Paris, midnight + noon):

    >>> import numpy as np
    >>> jd = np.array([2459656.5, 2459657.0])  # 2022-03-20 00:00 + 12:00 UT
    >>> is_day_chart(jd, 48.8566, 2.3522)
    array([False,  True])

    Polar safety (Tromsø, J2000 noon — Porphyry fallback prevents raise):

    >>> is_day_chart(2451545.0, 69.65, 18.96)
    array(True)
    """
    # 1. Broadcast (mirror compute_chart)
    jd_a  = np.asarray(jd,  dtype=np.float64)
    lat_a = np.asarray(lat, dtype=np.float64)
    lon_a = np.asarray(lon, dtype=np.float64)
    jd_b, lat_b, lon_b = np.broadcast_arrays(jd_a, lat_a, lon_a)

    # 2. Compute houses with Porphyry polar fallback (D-15) — always.
    #    System is fixed to "placidus" because the day/night answer does
    #    not depend on which house system : it depends on the ASC and
    #    above-horizon hemisphere only, which Porphyry preserves.
    houses = calculate_houses(
        jd_b, lat_b, lon_b,
        system="placidus", polar_fallback="porphyry",
    )

    # 3. Sun longitude per element — single-body batch call (body_id=0).
    sun_lon = calc_planet_position_batch(
        jd_b.ravel(), 0
    )[:, 0].reshape(jd_b.shape)

    # 4. Map Sun to its natal house (D-14).
    sun_house = house_of(sun_lon, houses["cusps"])

    # 5. Houses 7..12 = above horizon = day (D-13/D-14).
    return cast(np.ndarray, sun_house >= 7)
```
