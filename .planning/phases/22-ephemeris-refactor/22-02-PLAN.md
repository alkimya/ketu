<objective>
Split the 859-LOC `ketu/ephemeris/orbital.py` into focused private sub-modules while keeping
`orbital.py` as a byte-identical public re-export hub. Behavior must be byte-stable — this is a pure
file-reorganization with zero algorithm changes.

(_kepler / _mechanics / _perturbations / _body_getters) plus a shared _elements data module give
Phase 24 clean seams to add Chiron's orbital row and getter.

Output: `_elements.py`, `_kepler.py`, `_mechanics.py`, `_perturbations.py`, `_body_getters.py`, and
a slimmed `orbital.py` (~hub) — all existing imports unchanged.
</objective>
