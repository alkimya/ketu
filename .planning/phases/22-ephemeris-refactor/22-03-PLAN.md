  directory level beneath it).

  a HighLatitudeError mask real bugs (Pitfall 3 ratchet from Phase 16).

  triples (jd/lat/lon) — NOT CHART_DTYPE. Move them verbatim (including their exact JD/lat/lon
  values and docstrings) to the root conftest. Do not "harmonize" the chart_* lat/lon with the
  natal_* values — they are independent fixtures with different purposes.
- KEEP in each subpackage conftest the subpackage-specific code: `oracle_fixture`, `ORACLE_SLUGS`,
  `load_oracle_fixture` (synastry and composite have DIFFERENT fixture JSON dirs and DIFFERENT
  mandatory keys — do NOT merge these into the root).
- Do NOT touch `tests/charts/conftest.py` — it only re-exports houses oracle fixtures and defines no
  natal/chart fixtures (out of REF-03 scope per Research 3C).
- No fixture NAME collisions (Research 3D verified): chart_* live only in synastry+composite;
  natal_* live only in returns; cli/houses conftests use disjoint names. Moving to root is safe.
- Session scope is intended and correct: synastry and composite tests will now share the SAME
  chart_* instances. Tests do not mutate the returned arrays (Research Pitfall 5), so sharing is
  safe.
- Coverage stays 100% (conftest.py files are test infra, omitted via `*/tests/*` — verify they are
  not accidentally counted).
