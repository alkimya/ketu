- **Fix:** After running the babel script, applied a Python one-liner to replace `charset=utf-8` with `charset=UTF-8` in all 5 files.
- **Files modified:** arabic_parts.po, chiron.po, houses.po, predictive_charts.po, relational_charts.po
- **Verification:** `grep -q "charset=UTF-8"` returned OK for all 5 files; msgfmt compiled all without error
