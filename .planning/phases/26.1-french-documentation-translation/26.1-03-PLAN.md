## Marker-Preservation DO/DON'T (CRITICAL — breaks the build if violated)

DON'T:
- NEVER add `#`, `##`, `###` heading markers to a msgstr when the msgid has none (the
  Phase 25-03 `myst.header` bug).
- NEVER translate `{ref}`...``, `{doc}`...``, or any `{role}`...`` MyST role — copy verbatim.
  index.po contains toctree entries and {doc}/{ref} roles — these MUST stay verbatim.
- NEVER translate a msgid that is ENTIRELY a code span (backtick to backtick) — copy verbatim.
- NEVER drop `` `` `` backticks, `**bold**`, URLs, or shape notation like `(14, 14)`.

DO:
- Translate prose headings and page titles: `msgid "House Systems"` → `msgstr "Systèmes de maisons"`.
- Keep `**bold**`, translate inside, add FR colon space: `**Parameters:**` → `**Paramètres :**`.
- Keep backtick code (function/class names, `compute_chart`, `CHART_DTYPE`) verbatim.
- FR colon spacing: a space before `:` `;` `!` `?`.
- Multiline: single-line msgstr valid for short entries; concatenated quoted strings for long.

Skip `#~`-prefixed obsolete entries. Only fill empty `msgstr ""` entries.
