  <action>
Replace the entire content of `.github/workflows/publish.yml` with a modern trusted publishing workflow. The current workflow uses API tokens (secrets.PYPI_API_TOKEN) and is set to manual trigger only. Replace with the PyPA-recommended trusted publishing pattern:

```yaml
name: Publish to PyPI

on:
  push:
    tags:
      - 'v*.*.*'

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Install build dependencies
        run: python -m pip install --upgrade pip build
      - name: Build distributions
        run: python -m build --sdist --wheel
      - name: Validate with twine
        run: |
          pip install twine
          twine check dist/*
      - name: Store distributions
        uses: actions/upload-artifact@v4
        with:
          name: python-package-distributions
          path: dist/

  publish-to-pypi:
    needs: build
    runs-on: ubuntu-latest
    environment: pypi
    permissions:
      id-token: write
    steps:
      - name: Download distributions
        uses: actions/download-artifact@v4
        with:
          name: python-package-distributions
          path: dist/
      - name: Publish to PyPI
        uses: pypa/gh-action-pypi-publish@release/v1
```

Key changes from old workflow:
- Trigger on version tags (v*.*.*) instead of manual-only
- Uses trusted publishing (OIDC) instead of API tokens — no secrets needed
- Separates build and publish into distinct jobs
- Adds twine validation step before upload
- Uses `pypa/gh-action-pypi-publish` official action
- Requires `id-token: write` permission for OIDC
- Uses `environment: pypi` for optional manual approval gate

NOTE: The user must configure the trusted publisher on PyPI (one-time setup). This is documented in the checkpoint in Plan 02.

```python
"""Verify version synchronization across project."""

import re

from importlib.metadata import version


def test_version_matches_metadata() -> None:
    """Ensure __version__ matches installed package metadata."""
    import ketu

    installed_version = version("ketu")
    code_version = ketu.__version__

    assert installed_version == code_version, (
        f"Version mismatch: package metadata={installed_version}, "
        f"ketu.__version__={code_version}"
    )


def test_version_format() -> None:
    """Verify version follows semantic versioning."""
    import ketu

    semver_pattern = r"^\d+\.\d+\.\d+(?:-[a-zA-Z0-9.]+)?(?:\+[a-zA-Z0-9.]+)?$"

    assert re.match(semver_pattern, ketu.__version__), (
        f"Version {ketu.__version__} does not follow semantic versioning"
    )
```
