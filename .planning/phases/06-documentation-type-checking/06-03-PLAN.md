    ketu/aspects/transits.py

    ketu/cache/__init__.py
    ketu/resonance.py
    ketu/lunar_calendar.py
    ketu/display.py
  </files>
  <action>
    **Step 1: Install mypy in ketu venv.**
    ```bash
    source venv/bin/activate
    pip install mypy
    ```

    **Step 2: Add mypy configuration to pyproject.toml.**
    Add after `[tool.coverage.report]`:
    ```toml
    [tool.mypy]
    python_version = "3.11"
    strict = true
    plugins = ["numpy.typing.mypy_plugin"]
    warn_return_any = true
    warn_unused_configs = true

    [[tool.mypy.overrides]]
    module = ["swisseph.*"]
    ignore_missing_imports = true

    [[tool.mypy.overrides]]
    module = [
        "ketu.cycles.*",
        "ketu.aspects.timelines",
        "ketu.aspects.calculator",
        "ketu.aspects.core",
        "ketu.aspects.windows",
        "ketu.aspects.transits",
        "ketu.resonance",
        "ketu.lunar_calendar",
    ]
    disable_error_code = ["misc"]

    [[tool.mypy.overrides]]
    module = "tests.*"
    disallow_untyped_defs = false
    ```

    **Step 3: Run mypy incrementally (fix module by module).**

    Start with simplest modules, work toward complex:
    1. `mypy ketu/core.py --strict` — Fix any issues
    2. `mypy ketu/ephemeris/time.py --strict` — Fix any issues
    3. `mypy ketu/ephemeris/coordinates.py --strict` — Fix any issues
    4. `mypy ketu/calculations.py --strict` — Fix any issues
    5. `mypy ketu/complex.py --strict` — Fix any issues
    6. `mypy ketu/ephemeris/planets.py --strict` — Fix with swisseph override
    7. `mypy ketu/ephemeris/orbital.py --strict` — Fix any issues
    8. `mypy ketu/cache/ --strict` — Fix any issues
    9. `mypy ketu/cycles/ --strict` — Fix with misc override for structured arrays
    10. `mypy ketu/aspects/ --strict` — Fix with misc override
    11. `mypy ketu/resonance.py --strict` — Fix any issues
    12. `mypy ketu/lunar_calendar.py --strict` — Fix any issues
    13. `mypy ketu/display.py --strict` — Fix any issues
    14. `mypy ketu/ --strict` — Final full check

    **Common fixes expected:**
    - Add missing type hints to parameters (some functions may use `l_bodies=bodies` without type)
    - Add return type annotations where missing
    - Replace bare `list`, `dict`, `tuple` with `List`, `Dict`, `Tuple` from typing
    - Add `Optional` for parameters that can be None
    - Use `np.ndarray` (not `NDArray`) for structured array returns
    - Add `# type: ignore[import-untyped]` ONLY for swisseph imports (prefer override instead)
    - Fix `Any` usage — replace with specific types
    - Ensure `__all__` lists in `__init__.py` files for `--no-implicit-reexport`

    **Step 4: Ensure py.typed marker exists.**
    Check `ketu/py.typed` exists (already referenced in pyproject.toml package-data). Create if missing:
    ```bash
    touch ketu/py.typed
    ```

    **Step 5: Run full mypy check.**
    ```bash
    mypy ketu/ --strict
    ```
    Must exit with 0 errors. Warnings are acceptable.

    **Rules:**
    - Do NOT add `# type: ignore` comments unless absolutely necessary (swisseph interop)
    - Do NOT change function behavior — only add/fix type annotations
    - PREFER mypy overrides in pyproject.toml over inline ignores
    - Keep structured array returns typed as `np.ndarray` (not `NDArray[np.void]`)
    - If a function truly returns `Any` from swisseph, annotate the wrapper's return type explicitly
  </action>
  <verify>
    `source venv/bin/activate && mypy ketu/ --strict 2>&1 | tail -1` shows "Success" or 0 errors.
    `grep "strict = true" pyproject.toml` returns a match.
    `ls ketu/py.typed` exists.
    `pytest tests/ -x -q` passes (type hint changes didn't break runtime).
  </verify>
  <done>
    mypy strict mode configured in pyproject.toml. `mypy ketu/ --strict` passes with 0 errors. All public functions have complete type annotations. py.typed marker exists for PEP 561 compliance. All 250 tests pass.
  </done>
