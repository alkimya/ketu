    Convert all public function and class docstrings to NumPy-style (numpydoc) format. These are the highest-traffic modules — the public-facing API.

    **Format template:**
    ```python
    def func(param1: type1, param2: type2) -> return_type:
        """Short description (one line, imperative mood).

        Extended description if needed (1-2 sentences).

        Parameters
        ----------
        param1 : type1
            Description of param1.
        param2 : type2
            Description of param2.

        Returns
        -------
        return_type
            Description of return value.

        Raises
        ------
        ValueError
            If condition is invalid.

        Notes
        -----
        Precision: ±X° for Y (where relevant).

        Examples
        --------
        >>> from ketu.calculations import func
        >>> func(arg1, arg2)
        expected_output
        """
    ```

    **ketu/__init__.py (~30 lines → ~50 lines):**
    - Add precision guarantees section to module docstring
    - Document: angular separation ±1e-6°, planetary positions ±0.1° inner / ±0.5° outer
    - Document: best accuracy range 1800-2200 CE
    - Reference submodules with brief descriptions

    **ketu/calculations.py (15 functions):**
    Convert existing Google-style ("Args:", "Returns:") to numpydoc format for ALL:

    - Add `Examples` section to each with realistic astronomical data
    - Add `Notes` section with precision info to `long`, `distance`, `body_properties`

    **ketu/complex.py (3 classes + 10 functions):**
    Convert docstrings for:
    - Classes: `Aspect`, `ZodiacPoint`, `CycleRatio` — add class-level docstring with Attributes section

    - Add `Notes` section explaining complex representation: e^(iθ) = cos(θ) + i·sin(θ)

    **ketu/core.py:**
    - Add module-level docstring explaining bodies, aspects, signs data structures

    - Document aspect values (0°=conjunction, 180°=opposition, etc.)

    - Imperative mood for first line: "Convert" not "Converts"
