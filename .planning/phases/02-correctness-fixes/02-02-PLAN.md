<objective>
Fix BUG-02: aspect vectorization non-determinism where `calculate_aspects_vectorized()` returns different results than `calculate_aspects()`.

Purpose: On date 2020-12-21 18:20:00 UTC, the vectorized function finds 31 aspects while the loop version finds 30. The root cause is incorrect indexing in the inner loop at line 139: `orb_values[np.where(in_orb)[0] == idx][0]` creates a boolean mask lookup instead of using the sequential index into the already-filtered `orb_values` array. This can produce duplicate aspects (same pair counted twice at same orb value from wrong index) or different orb values.

Output: Fixed `ketu/aspects/calculator.py` with correct enumeration indexing, plus regression tests in `tests/test_regression/test_bug_02_aspects.py`.
</objective>

        if np.any(in_orb):
