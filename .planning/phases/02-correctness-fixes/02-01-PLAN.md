<objective>
Fix BUG-01: operator precedence in cache logic that allows cache to be used even when `use_cache=False`.

Purpose: The current boolean expression `use_cache and CACHE_AVAILABLE and hasattr(...) or isinstance(...)` evaluates as `((use_cache and CACHE_AVAILABLE and hasattr(...)) or isinstance(...))` due to Python's `and` binding tighter than `or`. This means passing `use_cache=False` with a list or ndarray of timestamps still enables the cache path. Users cannot disable caching.

Output: Fixed `ketu/cycles/calculator.py` with correct parenthesization, plus a regression test in `tests/test_regression/test_bug_01_cache.py`.
</objective>

use_ephemeris_cache = (
